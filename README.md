# NEXORA - Login & Signup

NEXORA is a full-stack authentication web application built using React, Vite, Node.js, and Express.

## Features

- Login and Signup
- Form validation
- React Router
- Axios API integration
- Responsive design
- Express backend
- Vercel deployment

## Technologies

- React
- Vite
- JavaScript
- CSS
- Node.js
- Express
- Axios
